# Wymagania Klienta (User Requirements)

- [x] URQ-01: Generowanie kodu QR z niestandardowym stylem
* **Opis:** Użytkownik musi mieć możliwość wygenerowania kodu QR w formacie SVG, w którym kształty modułów oraz kolory poszczególnych elementów (body, ramki, oczy) można w pełni modyfikować.
* **Źródło:** Klient / Specyfikacja UX
* **Priorytet:** Wysoki

- [x] URQ-101: Podgląd palet kolorów
* **Opis:** Użytkownik może przeglądać dostępne palety kolorów i zastosować wybraną paletę do kolorów elementów kodu QR.
* **Źródło:** Klient / Specyfikacja UX
* **Priorytet:** Średni
